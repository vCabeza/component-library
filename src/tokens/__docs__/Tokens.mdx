# Design Tokens

Figma is the absolute source of truth. Semantic and component layers only alias these values.

| Layer | Contents |
| --- | --- |
| Color | `SurfaceHigh`, `Inverse`, `Outline`, `OnNeutral`, … |
| Spacing | `0` … `2XL` with `{ px, rem }` |
| Typography | `body-m`, `body-s` (Inter) |
| Semantic | Intent aliases → Figma colors |
| Component | Button / Badge / Tabs maps |

## Usage

```ts
import {
  colorTokensDefinition,
  spacingTokensDefinition,
  spacingCss,
  typographyTokensDefinition,
  tokens,
} from "component-library";

colorTokensDefinition.Inverse;
spacingCss("S"); // "1rem"
typographyTokensDefinition["body-m"];
tokens.component.button.variant.primary.background;
```
