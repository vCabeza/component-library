# Button

Reference interactive component for this design system. Styles come from theme tokens; no hardcoded colors.

Supports `:focus-visible` rings, native `disabled`, and `@media (forced-colors: active)` adaptations. The default focus ring uses Figma `Outline` (documented contrast gap vs 3:1 UI AA — not overridden).

## Usage

```tsx
import { Button, ThemeProvider } from "component-library";

export function Example() {
  return (
    <ThemeProvider>
      <Button variant="primary" size="medium" onClick={() => {}}>
        Button
      </Button>
    </ThemeProvider>
  );
}
```

## Props

- **children** — Button content (text, icons, or composed nodes).
- **variant** — `"primary"` | `"secondary"`.
- **size** — `"small"` | `"medium"` | `"large"`.
- **disabled** — Disables interaction and applies disabled tokens.
- **onClick** — Click handler (`MouseEventHandler<HTMLButtonElement>`).
- Native `button` attributes are forwarded (e.g. `type`, `aria-*`).

See **Foundations / Accessibility** for contrast gaps, target-size notes, and AT checklist.
