# Tab

Standalone raw `<button type="button" role="tab">` — always in the sequential tab order (`tabIndex={0}`) unless disabled or an explicit `tabIndex` is passed. Inside `<Tabs>`, every enabled tab stays Tab-key reachable; arrows / Home / End change selection from the focused tab.

Disabled tabs use the native `disabled` attribute and semantic disabled color tokens (Figma-mapped). Forced-colors mode is supported.
