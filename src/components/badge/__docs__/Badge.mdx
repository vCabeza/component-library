# Badge

Static status badge. Surfaces map to Figma tokens `SurfaceHigh`, `SurfacePositive`, and `SurfaceNegative`. Text always uses `OnNeutral` with typography `body-s` at weight `700`.

Size is **viewport-driven** (no `size` / `mobile` prop):

- Desktop (`min-width: 769px`): height 26px, padding `3XS`/`2XS`, radius 12px
- Mobile (`max-width: 768px`): height 22px, padding `4XS`/`3XS`, radius 8px

Prefer clear visible labels so Positive/Negative meaning is not hue-only. For numeric or ambiguous chips, use `accessibilityLabel` (and `live` only for dynamic status updates).

## Usage

```tsx
import { Badge, ThemeProvider } from "component-library";

export function Example() {
  return (
    <ThemeProvider>
      <Badge variant="Positive">New</Badge>
      <Badge variant="Negative" accessibilityLabel="3 errors" live>
        3
      </Badge>
    </ThemeProvider>
  );
}
```

## Props

- **children** — Badge label content
- **variant** — `"Neutral"` | `"Positive"` | `"Negative"` (default `"Neutral"`)
- **accessibilityLabel** — optional `aria-label` when visible text is insufficient
- **live** — when `true`, `role="status"` + `aria-live="polite"` (default `false`)
- Native `span` attributes are forwarded (`id`, `aria-*`, etc.)

See **Foundations / Accessibility** for Figma gaps (`body-s`, mobile height) and AT checklist.
